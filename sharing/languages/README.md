# Ink3DS 0.6.5 — language gallery

Nine language variants, each showing an original-language book above and a translated interface below.
**Host-rendered previews from the real parser/layout/UI code, not device screenshots.**
Fonts are rasterized from their matching TTF sources on the PC, so rendering can differ on hardware.
Books were opened as EPUBs; the displayed excerpts were not pasted into the reader.
Offsets, source URLs and EPUB hashes are recorded in manifest.json. Entire books are not included.
